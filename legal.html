Pendant une partie

  • Connexion directe entre joueurs. Les parties passent directement d'un navigateur à l'autre (technologie WebRTC). Comme pour tout jeu en réseau direct, les joueurs d'un même salon peuvent techniquement voir l'adresse IP des autres joueurs du salon. Ne jouez qu'avec des personnes à qui vous donnez le code.
  • Mise en relation. Pour se trouver, les navigateurs passent par le serveur public gratuit de PeerJS (0.peerjs.com), qui voit votre adresse IP et un identifiant de salon temporaire.
  • Relais réseau. Si votre réseau bloque la connexion directe, le trafic du jeu passe par un relais de la société Metered (Canada). D'après sa politique de confidentialité, Metered relaie ce trafic sans l'inspecter, le stocker ni l'enregistrer, et conserve 30 jours les métadonnées de connexion (adresses IP, horaires, volume).
  • Messages du salon. Les messages de discussion et les pseudos circulent uniquement entre les joueurs du salon et ne sont pas enregistrés.

Mesure d'audience

Pour savoir combien de personnes jouent et à quels jeux, le site utilise GoatCounter (goatcounter.com), un outil de statistiques sans cookie qui ne suit pas les visiteurs d'un site à l'autre et ne crée pas d'identifiant persistant. Sont comptés : la page visitée, le site d'où vous venez, le type de navigateur et d'appareil, la taille d'écran, le pays déduit de l'adresse IP (l'adresse elle-même n'est pas conservée), et des événements anonymes (salon créé ou rejoint, partie lancée avec le nom du jeu et le nombre de joueurs, QR code ouvert, lien ou résultat partagé, clic sur le café ou les idées). Jamais votre pseudo, le code de votre salon ni le contenu du chat. Ces statistiques ne servent qu'à améliorer le jeu ; elles relèvent de l'intérêt légitime de l'éditeur, et vous pouvez les bloquer avec un bloqueur de publicité ou de traqueurs.

Liste publique des salons

Si vous créez un salon sans cocher « Salon privé », les informations suivantes apparaissent dans la liste des salons ouverts, visible par tous les visiteurs : le code du salon, le pseudo du créateur, le jeu choisi et le nombre de joueurs. Cochez « Salon privé » pour ne pas apparaître dans cette liste.

Privacy

Baston Arcade asks for no account, no e-mail address and no payment details. The site sets no cookies and uses no advertising or analytics.

Data kept in your browser

Your nickname, sound setting, language and game history (leaderboard) are stored only in your browser's local storage. They are never sent to a server run by the publisher. You can erase them at any time from the leaderboard ("Clear history") or by clearing this site's data in your browser.

During a game

  • Direct connection between players. Games run directly from one browser to another (WebRTC). As with any peer-to-peer game, players in the same room can technically see the IP addresses of the other players in that room. Only play with people you give the code to.
  • Matchmaking. To find each other, browsers use the free public PeerJS server (0.peerjs.com), which sees your IP address and a temporary room identifier.
  • Network relay. If your network blocks direct connections, game traffic goes through a relay run by Metered (Canada). According to its privacy policy, Metered relays this traffic without inspecting, storing or recording it, and keeps connection metadata (IP addresses, times, volume) for 30 days.
  • Room messages. Chat messages and nicknames travel only between the players in the room and are not stored.

Audience measurement

To know how many people play, and which games, the site uses GoatCounter (goatcounter.com), a cookie-free analytics tool that does not follow visitors from site to site or create a persistent identifier. It counts: the page visited, the site you came from, the browser and device type, the screen size, the country derived from the IP address (the address itself is not kept), and anonymous events (room created or joined, game started with the game's name and the number of players, QR code opened, link or result shared, click on the coffee or ideas buttons). Never your nickname, your room code or the chat. These statistics are only used to improve the game, on the basis of the publisher's legitimate interest, and you can block them with an ad or tracker blocker.

Public list of rooms

If you create a room without ticking "Private room", the following appears in the list of open rooms, visible to every visitor: the room code, the host's nickname, the chosen game and the number of players. This is stored with Supabase (database, servers in Frankfurt, Germany, region eu-central-1), deleted when the room closes and no longer shown after 90 seconds without activity. Tick "Private room" to stay off this list.
